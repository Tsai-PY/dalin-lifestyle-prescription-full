第一章：系統簡介與雙核心架構

「嘉義縣大林鎮生活處方完整版系統」 是依據生活型態醫學（Lifestyle Medicine）六大基石專為大林鎮民量身打造之智慧生活指引地圖。系統整合大林鎮全境共計 271 處 社區生活處方資源點，並採用現代化雙核心模組化架構，將「前台日常民眾查詢」與「後台管理者圖資維護」完美整合於單一系統中。

🔄 雙核心切換模式

系統頂部設有清晰的兩大模組切換方框，使用者或管理者可依當前任務一鍵切換：

1 第一部分：生活處方資料查詢

供鎮民、醫療醫事人員、社區志工查詢生活處方。輸入當前位置或點擊地圖即可自動計算大林鎮現有道路網絡，推薦最近 5 處服務點並規劃行車、步行或自行車路線。

2 第二部分：生活處方資料維護

依 Google My Maps（我的地圖）標準操作模式設計，採單一圖層聚焦維護。支援在邊界內新增標記、修改名稱說明、更換照片、匯出/匯入 KML 備份等完整功能。

第二章：第一部分「資料查詢模組」操作指南

查詢模組採用左側四步驟引導式操作與右側即時互動地圖連動設計，讓長輩與初次使用者皆能輕鬆上手。

📍 起點與所在位置設定

  • 預設起點：預設為「大林鎮公所」（經緯度：23.602568, 120.471415）。
  • 📍 重新定位：點擊「重新定位」按鈕，系統將自動請求瀏覽器 GPS 權限，取得使用者當前真實座標。
  • 地圖自訂起點：直接在右側地圖上任何地點按下滑鼠左鍵（或於觸控螢幕輕點），系統將立即將該位置設為新的起點「我」，並重新計算所有處方點距離。
  • 🗺️ 大林鎮公所：點擊即可快速將起點還原為大林鎮公所。

🔢 查詢核心四步驟

1步驟 1：選擇生活處方領域

點擊欲諮詢的處方領域（如「飲食健康」或「藥物安全」）。按鈕上會直接標示該領域共有幾處大林在地服務點。

2步驟 2：選擇前往交通方式

可選「🚗 開車」、「🚶 步行」或「🚲 腳踏車」。系統將根據真實道路拓撲網格與平均移動速度換算精準路線與到達時間。

3步驟 3：瀏覽最近五個服務點

畫面會立即呈現距離起點最近的 5 個推薦服務點，標示 1～5 名、直線與路程距離、預估時間膠囊，並提供關鍵字即時篩選。

4步驟 4：查看詳細資訊與導航

點選任一點位後，步驟 4 即時顯示真實地址、聯絡電話、營業時間、說明與照片，並連動右側地圖畫出沿道路之導航軌跡。

💡 最新優化特點：
系統於查詢功能啟動或切換處方分類時，畫面上與地圖上立即看得到最近的五個服務點！ 左側清單直接完整展開呈現第 1 至第 5 名的完整資訊卡；右側地圖亦自動調整邊界縮放（fitBounds），確保起點「我」與 1～5 號服務點標記同時完整呈現在視野內，不被畫面邊緣遮蔽。

🗺️ 右側互動地圖導航與工具列

  • 起點標記：以顯眼的藍色立體圖釘標示「我」。
  • 服務點標記：以處方領域專屬顏色標示「1、2、3、4、5」數字圖釘，當前選取的服務點會放大並帶有立體黑外框。
  • 道路導航路線：具備深藍光暈外框與導航藍主線，兩端點亦繪製正交接入路緣之步行動線虛線。
  • 工具列按鈕：
    • 📍 顯示最近5點：一鍵重置地圖視角，完整囊括起點與前 5 大最近服務點。
    • 🧭 聚焦規劃路線：針對當前選取的特定服務點與導航路徑進行細部放大檢視。
  • 游標指到即時預覽：當滑鼠移到左側列表或地圖標記上方時，系統會自動跳出即時浮動預覽卡片，顯示該處方點之最新文字說明與現場實景照片。

第三章：第二部分「資料維護模組」操作指南

點擊頂部模式切換列的「第二部分：生活處方資料維護」即可進入後台管理工作台。 維護模組全面遵循 Google My Maps（我的地圖） 之工作邏輯，以單一圖層獨立開啟、防呆檢核與在地化邊界防護為核心準則。

📋 六大處方圖層單一開啟維護

為避免多圖層混雜造成管理人員誤刪誤改，維護模式嚴格維持「單一處方圖層開啟」原則：

  1. 於左側圖層清單點選欲維護之處方圖層（例如：「藥物安全」或「飲食健康」）。
  2. 地圖即時切換為該圖層專屬之所有服務點標記，左側下半部列表亦同步過濾為該圖層點位。
  3. 清單上方提供即時關鍵字過濾搜尋框，輸入關鍵字可即時篩選名稱或地址。

🛠️ 服務點檢視與修改工作面板

在左側點選任何服務點，中央檢視面板會呈現完整詳細欄位：

  • 名稱（Name）：服務點之標準名稱（如：大林慈濟醫院藥劑部）。
  • 處方類別（Category）：下拉選單可調整歸屬圖層（支援跨圖層搬移）。
  • 經緯度座標（Coordinates）：顯示緯度與經度，可手動輸入或直接在地圖上拖曳標記。
  • 說明內容（Description）：該生活處方點之服務細節、適合對象、健保服務或活動時間。
  • 現場實景照片（Images）：可貼入公開圖片網址，或直接點選「上傳本機照片」附加至該處方點。

第四章：服務點新增、編輯與座標防呆

➕ 新增服務點之標準操作流程

  1. 確認目前開啟的為欲新增之正確處方圖層。
  2. 點擊上方 「➕ 在此圖層新增處方服務點」 按鈕。
  3. 地圖進入「點擊選點模式」，直接在右側地圖上目標位置點擊左鍵。
  4. 系統自動拾取點擊位置之經緯度座標，並載入大林鎮在地化地理邊界防護進行即時檢核。
  5. 於彈出之表單中填寫「服務點名稱」、「詳細說明」、「地址」與「圖片」。
  6. 點擊「確認儲存」，新點位立即寫入系統本機快取與資料庫中。
⚠️ 大林鎮地理邊界嚴密防呆機制：
系統內建嘉義縣大林鎮法定轄區範圍多邊形演算法（包含大林鎮 21 里全境共 223 處精密邊界節點之 isPointInDalinPolygon 演算法）。
若新增或修改之經緯度座標超出大林鎮轄區範圍（例如點到民雄、溪口或梅山轄區），系統將立即彈出防呆警示並拒絕儲存！此防呆機制可徹底杜絕人為誤點或外鄉鎮資料錯置。

✏️ 編輯與更新現有服務點

點選清單任一點位後，於右側編輯欄修改文字或照片，按下 「💾 儲存修改」 即時更新。
若需微調座標，亦可直接點擊地圖上的標記並拖曳至正確街道門牌位置。

🗑️ 刪除服務點防護

點擊檢視區下方的 「🗑️ 刪除此服務點」 按鈕時，系統會跳出雙重確認視窗，避免誤按。刪除後即時自該處方圖層中移除並重新計算總點數。

第五章：資料同步、KML 匯入／匯出與還原

💾 匯出 KML 備份檔案（相容 Google Earth / My Maps）

在維護工作完成後，強烈建議匯出備份檔案：

  1. 點擊維護工具列之 「💾 匯出／備份 KML」 按鈕。
  2. 在對話框中選擇匯出範圍：
    • 整個地圖：匯出完整 6 個處方圖層、271 處服務點資料。
    • 僅目前圖層：僅匯出當前維護之單一圖層點位。
  3. 點擊「⬇️ 下載 KML 備份檔」，系統會自動產生標準 .kml 格式檔案下載至您的電腦或 iPad「下載項目」中。

📂 匯入最新 KML 檔案

若有自 Google My Maps 下載之最新 KML 檔，或同仁備份之更新檔案：

  1. 點擊頂部標頭列的 「📂 匯入 KML 檔」 按鈕。
  2. 選取電腦中的 .kml 檔案。
  3. 系統將自動解析 Placemark 節點、圖層樣式顏色、坐標與說明內容，並即時更新至畫面與資料庫中。

🔄 同步與一鍵還原預設資料庫

  • 🔄 同步最新資料：位於頂部標頭列藍色按鈕。用於多台 iPad 或電腦需要即時拉取最新官方線上版點位與圖片資料時使用。
  • 🔄 還原系統預設資料：位於維護區底部「進階管理」按鈕。若資料操作錯誤或被不慎大量更動，點擊即可一鍵復原回最初始經過嚴格審核的大林鎮 271 處標準生活處方資料庫。

第六章：Google Maps API 金鑰設定指南

系統具備雙模式運作彈性：「官方 Google Maps 向量地圖即時聯網模式」 與 「免金鑰 SVG 相對方位雷達降級預覽模式」。

🔑 設定 API Key 的效益

  • 啟用真實街道 Google Maps 向量地圖與街景檢視。
  • 透過 Google Places API (New) 自動查詢店家真實門牌地址、電話與今日營業時間。
  • 透過 Google Routes API 依據即時路況計算最快行車與步行路程及到達時間。

🛠️ 免費申請測試用 Maps Demo Key 步驟

  1. 前往 Google Maps Demo Key 申請頁面。
  2. 使用一般 Google 帳號登入並勾選同意條款。
  3. 點擊產生測試用金鑰（Demo Key），並將金鑰字串複製。
  4. 回到生活處方系統，點選右上角 「🔑 API 金鑰」 按鈕。
  5. 將金鑰貼入輸入框中並點擊「儲存並啟用金鑰」。系統立即自動連線升級為完整版互動地圖。
🔒 安全性承諾：
您所輸入的金鑰僅會安全儲存在您當前設備之瀏覽器本機儲存區（localStorage），絕不會透過網路外傳或記錄至伺服器端，充分保障您的帳戶隱私與配額安全。

第七章：常見問題排解與操作技巧 (FAQ)

Q1：在手機或 iPad 上點選「📍 重新定位」為何沒有反應？

解答：行動瀏覽器（如 Safari、Chrome）因隱私政策要求，必須在使用者明確授權下才能存取位置：

  1. 請檢查網址列左側是否有「🔒」圖示，點擊並進入「網站設定」，將「位置」設定為「允許」。
  2. iOS 裝置請至「設定」➔「隱私權與安全性」➔「定位服務」確認 Safari 的定位權限已開啟。
  3. 若仍無法定位，亦可直接於地圖上點選目前所在地點，系統一樣能完成精準測算。

Q2：在維護模式新增服務點時，跳出「座標超出大林鎮轄區範圍」提示？

解答：此為系統之在地化地理多邊形防呆機制。代表您點擊的位置落在民雄鄉、溪口鄉或梅山鄉等外轄區。請將地圖縮小並確認標記點位於大林鎮行政里轄區範圍內。

Q3：沒有 Google Maps API Key 時，系統可以正常使用嗎？

解答：可以！系統內建大林鎮現有道路路網拓撲幾何引擎（共計 2 萬餘節點與 3,219 條路網鏈結）與 SVG 距離雷達圖。即使在離線或無 API 金鑰狀態下，系統仍會以在地道路精準計算距離、行車時間並排列出前 5 大推薦點。

Q4：如何將本使用手冊列印成紙本或另存為 PDF 文件？

解答：本手冊已內建專業的列印版面樣式（@media print）：

  1. 點擊頁面頂部的 「🖨️ 列印手冊／另存為 PDF」 按鈕（或於鍵盤按下 Ctrl + P / Cmd + P）。
  2. 在列印對話框中，將「目的地」選擇為 「另存為 PDF」 或您的印表機。
  3. 紙張尺寸選擇 A4，邊界選擇「預設」即可產生專業排版之紙本手冊。
